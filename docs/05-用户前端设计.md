# LoomVec 用户前端（apps/web）初步设计

> 状态：主体已落地（2026-09，问答/视频/音频部分随 P3） · [00-项目核心文档](./00-项目核心文档.md) 的设计附件 · 范围：`apps/web` SPA

## 一、定位与边界

- **服务对象**：企业终端用户（知识空间的 owner / editor / viewer）。
- **核心职责**：知识空间管理（创建、成员邀请、角色协作）、资产上传与编辑（名称/标签/分类/元数据）、空间内检索与全空间聚合检索、问答（带引用与图谱证据链）、共享空间审核协作、公共空间链接开关（P5：仅可链接/断开作为问答检索源，不可进入浏览）。
- **边界（不做）**：不做平台系统运维（归管理端 apps/admin）；不做公共空间内容运营与用户分组管理（归运营端 apps/ops，见 docs/12）；不做 API Key/OAuth 应用管理（开放平台归管理端）；viewer 角色纯只读。

## 二、技术方案

| 项 | 决策 |
|---|---|
| 框架 | React 18 + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui（与运维端同栈、同组件库） |
| 布局 | 左侧全局导航（对话区常驻侧栏上部 + 空间管理 / 检索，底部通知与用户菜单）+ 空间详情页签导航 |
| 服务端状态 | TanStack Query；问答与任务事件走 SSE（SSE 随 P3 落地，见 docs/10） |
| API | 一律经 `packages/sdk-ts` 调用 `/api/v1` 用户域，禁止手写请求 |
| 认证 | 平台 JWT + OIDC 登录，与运维端同一身份体系 |
| 部署 | 静态资源，与运维端同构 |

## 三、角色能力矩阵（用户视角）

| 能力 | owner | editor | viewer |
|---|---|---|---|
| 检索 / 浏览 / 问答 | ✓ | ✓ | ✓ |
| 上传资产 | ✓ | ✓ | ✗ |
| 编辑资产（名称/标签/分类/元数据） | ✓（任意） | ✓（仅自己上传的） | ✗ |
| 删除资产 | ✓（任意） | ✓（仅自己上传的） | ✗ |
| 审核（先审后见空间：通过/驳回） | ✓ | ✗（可查看待审队列） | ✗ |
| 成员管理 / 邀请 | ✓ | ✗ | ✗ |
| 空间设置 / 删除空间 / 嵌入模型与分块预设选择 | ✓ | ✗ | ✗ |

personal 空间：创建者即唯一成员（owner），仅本人可见；shared 空间：owner 可邀请成员并分配角色。

## 四、信息架构与路由

```
/                        根路径直达 /chat（工作台已移除：入口与其它条目重复）
/chat                    对话（用户级）：侧栏上部会话区（新建 + 历史会话，点击载入）
/chat/:sessionId         对话详情：召回空间范围选择、SSE 流式问答
/spaces                  空间管理：我的空间列表（创建入口、类型标识、配额概览）
                         + 公共空间区（P5：经分组可见的空间卡片 + 链接开关，不可进入）
/s/:spaceId              空间详情（页签导航：资产 / 检索 / 图谱 / 审核 / 成员 / 设置）
/s/:spaceId/assets       空间资产管理（Finder 式：目录树三视图 + 右键操作 + 拖拽/上传 + 筛选）
/s/:spaceId/search       空间内检索
/s/:spaceId/graph        知识图谱（实体列表/统计/合并日志/回滚/重建，owner 管理）
/s/:spaceId/review       审核队列（owner/editor，先审后见空间）
/s/:spaceId/members      成员管理（owner）
/s/:spaceId/settings     空间设置（owner）
/a/:assetId              资产详情与定位预览（跨空间直达，按权限校验）
/search                  全空间聚合检索（"我的全部空间"）
/notifications           通知中心（未读徽标 / 单条已读 / 全部已读）
/profile                 个人中心（个人信息、各空间配额）
```

## 五、模块设计

### 5.1 空间管理
- 入口：侧栏「空间管理」，空间卡片点击进入空间详情（页签：资产 / 检索 / 图谱 / 审核 / 成员 / 设置；owner/editor 专属页签对 viewer 不渲染）；
- 创建向导：类型（personal/shared）→ 名称 → 嵌入模型与分块预设（**仅运营配置的白名单内可选**）；
- 成员管理：邀请（用户名 + 角色选择；邮箱邀请随 OIDC 于 P4）、成员列表、角色变更与移除（owner）；被移除者即时失去访问；
- 冷启动：首次登录（OIDC 域自动归属租户）若无任何空间，「空间管理」页展示创建空间引导（邀请接受页随 P4 落地）；
- **公共空间（P5，docs/12）**：「空间管理」页独立分区，列出经用户分组可见的公共空间（运营端创建维护）；
  用户只能通过**开关**设置是否"链接"，不能点击进入查看其内容（资产/检索接口无成员关系一律 403）；
  链接后该空间出现在问答召回空间选择器中（`usePublicSpaces` / `useSpaceLinkToggle` hooks）。

### 5.2 上传
- 入口：空间资产页 Finder 工具栏「上传」按钮 / 文件拖入内容区（拖到当前文件夹，悬停高亮提示）；
- 目标：上传进入当前浏览的文件夹（`folder_id` 挂靠目录树；根目录上传即不传 folder_id）；
- 链路：`POST /uploads` 获取预签名 → 客户端直传 RustFS（单对象直传 + checksum 去重预检；multipart 分片与断点重传后置）→ `POST /assets` 登记触发管线；
- 配额前置：上传前显示空间/用户余量，超限即时提示（后端仍有硬校验）；
- 去重提示：同空间上传相同内容（checksum 命中）时提示——跳过或另存为新版本；
- 处理状态跟踪：资产卡展示管线阶段（排队/解析/分片抽取/嵌入/索引/完成/失败）与进度，失败展示原因并可重试（owner/editor）。

### 5.3 资产管理
- Finder 式目录管理（`@loomvec/ui/components/finder`，web/ops 共用）：空间内树形文件夹 + 资产，三种视图——**列表**（名称/大小/状态/修改日期表格，文件夹置顶）、**图标**（缩略图网格，图片资产取详情缩略图）、**分栏**（macOS Finder 分栏视图，列链下钻 + 选中文件右侧快捷预览面板）；视图偏好本地持久化；
- 面包屑导航：工具栏显示当前路径（空间根 → 逐级文件夹），点击任一级跳转；
- 右键菜单（条目 / 空白区）：打开、重命名（行内编辑）、拷贝/剪切/粘贴（⌘C/⌘X/⌘V）、移到…/复制到…（目录树选择对话框，移动源子树禁选）、删除（AlertDialog 二次确认）、失败资产重试；空白区含新建文件夹/上传/粘贴/刷新；
- 拖拽：条目拖到文件夹行/分栏列/面包屑即移动（前端预校验防环，后端兜底）；文件拖入内容区即上传到当前文件夹；
- 多选：单击选中、⌘/Ctrl+单击加减选；Delete 键删除选中、Enter 打开；
- 筛选：类型/标签/分类/状态/审核状态（作用当前文件夹）；列表内处理状态（processing/ready/failed）与审核状态（pending_review/approved/rejected）双徽标，驳回即对 viewer 下架，运营下架的资产对 owner 展示状态与理由；
- 查看：双击资产在 Finder 容器上层展开**全幅覆盖查看层**（原始文件 × MinerU 解析结果 Tabs、上一/下一个导航、Esc 关闭；运营端另含 chunk 管理面板）——不再跳转详情页；`/a/:assetId` 详情页保留给检索命中深链与完整编辑视图（自动摘要、元数据、标签/分类编辑器按空间 schema、处理任务时间线、图谱状态；覆盖层内有入口链接）；
- 复制语义：资产复制共享原始对象、入队完整管线重新解析（配额按新资产计量）；文件夹复制递归进行，目标父下同名文件夹并入（合并），同级复制落「副本」后缀避让源自身；
- 编辑与删除按第三章能力矩阵执行；删除二次确认，连带向量与图谱溯源由后端级联清理（删除文件夹级联其内全部内容）。

### 5.4 检索
- 作用域切换：当前空间 / **全空间聚合**（"我的全部空间"）；
- 过滤器：资产类型、标签、分类、时间；
- 结果 = 语义单元卡片：内容高亮、来源资产（名称+类型图标）、相关度、所属空间（聚合模式）；
- **定位跳转**：每条结果可跳到原文精确位置（页码/图片/视频时间点，见 5.6）；
- **图谱证据链**（P3）：可展开实体→关系→实体路径，解释"为什么命中"。

### 5.5 问答（`pages/ChatPage.tsx` + `agent.ts` SSE 客户端）
- **用户级会话**（跨空间）：侧栏「对话」进入；左侧为会话列表（顶部新建按钮 + 历史标题，点击载入历史消息）；
- **会话绑定项目目录（可选）**：新会话首次提问前可在输入区填写项目目录（`workspace/projects/` 下的相对路径），随创建会话提交 `project_path`；绑定的会话在头部展示目录徽标，交付物约定写入该目录；
- **召回空间范围按会话配置**：会话详情内多选我的空间（P5 起**含已链接的公共空间**，label 带「（公共）」后缀；空 = 我的全部可检索空间），随时可改，下一问生效；范围与用户当前可检索空间取交集，被移出/断开链接/分组收回的空间内容即时剔除；
- **图谱联合召回常态开启**（无前端开关）：向量（dense+BM25）与图谱（路径/社区摘要/邻接补全）同请求融合召回；仅运维全局关停时自动降级；
- 流式回答（SSE），引用以 [n] 标注，**点击引用跳转到对应语义单元的定位**；无定位的引用不展示编号；
- 证据链面板：答案引用的关系路径可视化（graph_evidence）；
- LLM 不可用时问答入口禁用并提示原因，检索不受影响。

### 5.6 回溯定位器（核心差异化组件）
按语义单元的 `source_locator` 类型渲染：

| 资产类型 | 定位呈现 |
|---|---|
| 文档（PDF/Office） | 文档预览器跳转页码 + 版面区域高亮（MinerU 坐标） |
| 表格 | HTML 表格渲染 + 源文件页码 |
| 图片 | 原图查看器 |
| 视频 | 内嵌播放器 seek 到 `time_start`，高亮片段区间，侧栏展示该场景关键帧与转写文本；浏览器不可播格式走懒转码（首次播放触发，转码期间以关键帧+进度提示过渡） |
| 音频 | 播放器 seek 到时间点 + 转写文本高亮 |

### 5.7 审核协作
- 待审队列（owner/editor）：开启"先审后见"的共享空间中待审资产；
- 待审资产可见性：上传者本人与 owner/editor 可见（标注待审、不参与检索），viewer 不可见；
- 通过 / 驳回（驳回理由必填，通知上传者）；通过后资产对 viewer 可见并进入全空间检索。

### 5.8 个人中心
- 配额用量：存储量 / 文件数进度条（个人与所参与空间）；
- 通知：资产处理完成/失败、审核结果、被邀请/被移除、配额接近与耗尽告警；
- 登录信息：OIDC 身份来源。

## 六、关键交互约定

1. **viewer 只读**：写操作入口对 viewer 不渲染（而非禁用置灰）；
2. 引用必须可溯源：答案与检索结果的每条引用都可点击跳转定位；
3. 危险操作二次确认：删除资产确认；删除空间需输入空间名确认；
4. 上传与处理解耦：上传成功即入列表（处理中状态），无需等待管线完成；
5. 聚合检索结果按空间分组展示，过滤器跨空间生效；
6. 成员被移出空间即刻失去该空间访问，其会话与聚合检索结果即时剔除该空间内容。

## 七、API 与实时性

- 全部经 `sdk-ts` 调用户域接口：`spaces / members / assets / uploads / search / agent / review / notifications / public-spaces`（P5 公共空间列表与链接开关）；
- 上传直传三步：预签名 → 直传（单对象；multipart/断点重传后置）→ 登记；
- 检索：`POST /search`（scope = `space_id` 或聚合模式）；
- 智能体问答：用户级 `/agent/*`（会话 CRUD 含召回范围 `scope_space_ids` 与项目目录 `project_path`、SSE 流式返回，引用与证据链结构化下发；知识检索经 `/api/v1/mcp` 由智能体调用）。
- 任务状态：TanStack Query 轮询 + `asset.ready / asset.failed` SSE 事件驱动刷新。
