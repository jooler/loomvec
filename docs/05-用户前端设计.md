# LoomVec 用户前端（apps/web）初步设计

> 状态：主体已落地（2026-09，问答/视频/音频部分随 P3） · [00-项目核心文档](./00-项目核心文档.md) 的设计附件 · 范围：`apps/web` SPA

## 一、定位与边界

- **服务对象**：企业终端用户（知识空间的 owner / editor / viewer）。
- **核心职责**：知识空间管理（创建、成员邀请、角色协作）、资产上传与编辑（名称/标签/分类/元数据）、空间内检索与全空间聚合检索、问答（带引用与图谱证据链）、共享空间审核协作。
- **边界（不做）**：不做平台运营治理（归运维端）；不做 API Key/OAuth 应用管理（开放平台归运维端）；viewer 角色纯只读。

## 二、技术方案

| 项 | 决策 |
|---|---|
| 框架 | React 18 + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui（与运维端同栈、同组件库） |
| 布局 | 顶部全局条（空间切换器 + 聚合搜索入口 + 用户菜单）+ 空间内左侧导航 |
| 服务端状态 | TanStack Query；问答与任务事件走 SSE（SSE 随 P3 落地，见 docs/10） |
| API | 一律经 `packages/sdk-ts` 调用 `/api/v1` 用户域，禁止手写请求 |
| 认证 | 平台 JWT + OIDC 登录，与运维端同一身份体系 |
| 部署 | 静态资源，与运维端同构 |

## 三、角色能力矩阵（用户视角）

| 能力 | owner | editor | viewer |
|---|---|---|---|
| 检索 / 浏览 / 问答 | ✓ | ✓ | ✓ |
| 上传资产 | ✓ | ✓ | ✗ |
| 编辑资产（名称/标签/分类/元数据） | ✓（任意） | ✓（仅自己上传的） | ✗ |
| 删除资产 | ✓（任意） | ✓（仅自己上传的） | ✗ |
| 审核（先审后见空间：通过/驳回） | ✓ | ✗（可查看待审队列） | ✗ |
| 成员管理 / 邀请 | ✓ | ✗ | ✗ |
| 空间设置 / 删除空间 / 嵌入模型与分块预设选择 | ✓ | ✗ | ✗ |

personal 空间：创建者即唯一成员（owner），仅本人可见；shared 空间：owner 可邀请成员并分配角色。

## 四、信息架构与路由

```
/                        工作台：最近资产、我的空间、快捷入口
/spaces                  我的空间列表（创建入口、类型标识、配额概览）
/s/:spaceId/assets       空间资产列表（类型/标签/分类/状态筛选）
/s/:spaceId/upload       上传
/s/:spaceId/search       空间内检索
/s/:spaceId/chat         空间问答
/s/:spaceId/graph        知识图谱（实体列表/统计/合并日志/回滚/重建，owner 管理）
/s/:spaceId/review       审核队列（owner/editor，先审后见空间）
/s/:spaceId/members      成员管理（owner）
/s/:spaceId/settings     空间设置（owner）
/a/:assetId              资产详情与定位预览（跨空间直达，按权限校验）
/search                  全空间聚合检索（"我的全部空间"）
/assets                  跨空间聚合资产列表（P2 落地新增；类型/状态/标签筛选）
/profile                 个人中心（配额用量、登录信息、通知）
```

## 五、模块设计

### 5.1 空间管理
- 创建向导：类型（personal/shared）→ 名称 → 嵌入模型与分块预设（**仅运营配置的白名单内可选**）；
- 空间切换器：全局顶栏常驻，**切换空间即切换知识源**（检索/问答/资产列表随之切换）；
- 成员管理：邀请（用户名 + 角色选择；邮箱邀请随 OIDC 于 P4）、成员列表、角色变更与移除（owner）；被移除者即时失去访问；
- 冷启动：首次登录（OIDC 域自动归属租户）若无任何空间，工作台展示创建空间 / 接受邀请引导。

### 5.2 上传
- 入口：拖拽区 / 文件选择器；
- 链路：`POST /uploads` 获取预签名 → 客户端直传 RustFS（单对象直传 + checksum 去重预检；multipart 分片与断点重传后置）→ `POST /assets` 登记触发管线；
- 配额前置：上传前显示空间/用户余量，超限即时提示（后端仍有硬校验）；
- 去重提示：同空间上传相同内容（checksum 命中）时提示——跳过或另存为新版本；
- 处理状态跟踪：资产卡展示管线阶段（排队/解析/分片抽取/嵌入/索引/完成/失败）与进度，失败展示原因并可重试（owner/editor）。

### 5.3 资产管理
- 列表：类型/标签/分类/时间/状态筛选（处理状态 processing/ready/failed 与审核状态 pending_review/approved/rejected 双徽标；驳回即对 viewer 下架），卡片与表格（缩略图网格）双视图；运营下架的资产对 owner 展示状态与理由；
- 详情：自动摘要、元数据、标签/分类编辑器（按空间 schema）、处理状态、来源信息；
- 编辑与删除按第三章能力矩阵执行；删除二次确认，连带向量与图谱溯源由后端级联清理。

### 5.4 检索
- 作用域切换：当前空间 / **全空间聚合**（"我的全部空间"）；
- 过滤器：资产类型、标签、分类、时间；
- 结果 = 语义单元卡片：内容高亮、来源资产（名称+类型图标）、相关度、所属空间（聚合模式）；
- **定位跳转**：每条结果可跳到原文精确位置（页码/图片/视频时间点，见 5.6）；
- **图谱证据链**（P3）：可展开实体→关系→实体路径，解释"为什么命中"。

### 5.5 问答（P3 已落地：`pages/ChatPage.tsx` + `chat.ts` SSE 客户端）
- 作用域 = 当前空间；会话保存在服务端，可续聊；
- 流式回答（SSE），引用以 [n] 标注，**点击引用跳转到对应语义单元的定位**；无定位的引用不展示编号；
- 证据链面板：答案引用的关系路径可视化（graph_evidence）；
- LLM 不可用时问答入口禁用并提示原因，检索不受影响。

### 5.6 回溯定位器（核心差异化组件）
按语义单元的 `source_locator` 类型渲染：

| 资产类型 | 定位呈现 |
|---|---|
| 文档（PDF/Office） | 文档预览器跳转页码 + 版面区域高亮（MinerU 坐标） |
| 表格 | HTML 表格渲染 + 源文件页码 |
| 图片 | 原图查看器 |
| 视频 | 内嵌播放器 seek 到 `time_start`，高亮片段区间，侧栏展示该场景关键帧与转写文本；浏览器不可播格式走懒转码（首次播放触发，转码期间以关键帧+进度提示过渡） |
| 音频 | 播放器 seek 到时间点 + 转写文本高亮 |

### 5.7 审核协作
- 待审队列（owner/editor）：开启"先审后见"的共享空间中待审资产；
- 待审资产可见性：上传者本人与 owner/editor 可见（标注待审、不参与检索），viewer 不可见；
- 通过 / 驳回（驳回理由必填，通知上传者）；通过后资产对 viewer 可见并进入全空间检索。

### 5.8 个人中心
- 配额用量：存储量 / 文件数进度条（个人与所参与空间）；
- 通知：资产处理完成/失败、审核结果、被邀请/被移除、配额接近与耗尽告警；
- 登录信息：OIDC 身份来源。

## 六、关键交互约定

1. **viewer 只读**：写操作入口对 viewer 不渲染（而非禁用置灰）；
2. 引用必须可溯源：答案与检索结果的每条引用都可点击跳转定位；
3. 危险操作二次确认：删除资产确认；删除空间需输入空间名确认；
4. 上传与处理解耦：上传成功即入列表（处理中状态），无需等待管线完成；
5. 聚合检索结果按空间分组展示，过滤器跨空间生效；
6. 成员被移出空间即刻失去该空间访问，其会话与聚合检索结果即时剔除该空间内容。

## 七、API 与实时性

- 全部经 `sdk-ts` 调用户域接口：`spaces / members / assets / uploads / search / chat / review / notifications`；
- 上传直传三步：预签名 → 直传（单对象；multipart/断点重传后置）→ 登记；
- 检索：`POST /search`（scope = `space_id` 或聚合模式）；
- 问答：SSE 流式返回，引用与证据链结构化下发；
- 任务状态：TanStack Query 轮询 + `asset.ready / asset.failed` SSE 事件驱动刷新。
