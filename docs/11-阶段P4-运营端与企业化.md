# P4 运营端与企业化

> 上级：[06-开发计划总览](./06-开发计划总览.md) · 目标：**企业生产就绪**——运维端全功能、OIDC SSO、OAuth 应用、Webhook、审计与监控告警、重嵌入工具链、K8s 部署、发布合规核对。

## 一、范围

**做**：管理 API 域（`/api/v1/admin/*`）与运维端全部页面（按 04 文档 IA）、OIDC 对接企业 IdP、OAuth 2.0 授权码流程、Webhook 投递体系、审计完善、重嵌入与索引重建工具链、监控告警（Prometheus/Grafana 面板 + 告警规则）、K8s 编排与 Helm、MinerU 条款合规核对。
**不做**：数据源连接器、MCP Server（列为 P4 后的生态阶段）；运维端不做用户视角权限诊断（已定边界）。

## 二、任务分解

### API 服务（管理域）

| # | 任务 | 要点 |
|---|---|---|
| P4-API-01 | 管理 API 域 | `/api/v1/admin/*` 路由域、admin scopes、平台角色守卫（super_admin/operator/auditor）、审计中间件强制 |
| P4-API-02 | 状态聚合接口 | 七组件健康、队列深度、管线吞吐/失败率/耗时分位、平台规模统计、备份状态 |
| P4-API-03 | 治理接口 | 租户 CRUD/停用（冻结语义）/OIDC 域绑定；用户禁用与平台角色；空间治理（封禁/owner 转移/清空）；配额调整 |
| P4-API-04 | 运营接口 | 审核队列（跨空间）/下架（连带清理）/批量重跑/重嵌入任务/图谱重建与实体合并收编 |
| P4-API-05 | 配置接口 | AI 供方/检索参数/上传策略/SSO/扩展 manifest 的读写（敏感值脱敏回显）；即时生效与需重启项标注 |
| P4-API-06 | OIDC 对接 | 授权码流程对接 IdP、用户自动开通与租户域归属、首次登录引导状态 |
| P4-API-07 | OAuth 应用 | oauth_client 管理、授权码流程、用户级令牌（权限不超用户本人）、同意页 |
| P4-API-08 | Webhook | 事件订阅管理、签名投递、重试与死信、投递日志 |

## 三、退出标准

- [ ] 运维端可完成：建租户→配域→用户域内登录→建空间→上传→审核→检索的全链路监管；
- [ ] 企业 IdP 登录可用；第三方应用经 OAuth 以用户身份调用 API；
- [ ] Webhook 事件可订阅、可重放；审计可导出；
- [ ] K8s 一键部署（Helm）+ 监控告警生效 + 备份恢复演练通过；
- [ ] 发布清单全绿，进入试运行。
