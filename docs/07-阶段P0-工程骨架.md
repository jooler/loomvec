# P0 工程骨架

> 上级：[06-开发计划总览](./06-开发计划总览.md) · 目标：**可开发的空转系统**——脚手架、基础设施栈、CI、健康检查全部就绪，后续各阶段只在既有轨道上加代码。

## 一、范围

**做**：monorepo 脚手架、compose 基础设施栈（含 MinerU 与 AGE 可用性验证）、配置/日志/追踪骨架、迁移框架与基础表、API 骨架与错误契约、双前端壳子与登录页、测试框架。
**不做**：任何业务功能（资产/检索/图谱）、真实认证对接（dev token 代替）、前端业务页面。

## 二、任务分解

### INF 基础设施

| # | 任务 | 要点 |
|---|---|---|
| P0-INF-01 | monorepo 脚手架 | uv workspace：`services/core`（loomvec-core）、`services/api`、`services/worker`；pnpm workspace：`apps/web`、`apps/admin`、`packages/sdk-ts`（占位）；ruff + eslint/prettier + pre-commit |
| P0-INF-02 | compose 基础设施栈 | `deploy/compose`：PG18+AGE（验证扩展可加载，必要时自建镜像）、Milvus Standalone、RustFS、Redis、**MinerU（含模型缓存卷，验证解析服务可调用）**、healthcheck 全覆盖、`.env.example` |
| P0-INF-03 | CI 流水线 | lint + 后端测试 + 前端测试 + 契约生成检查 + Docker 镜像构建（api/worker/web/admin） |
| P0-INF-04 | 可观测性骨架 | 结构化日志（JSON）、OpenTelemetry trace 骨架、Prometheus 指标端点、请求 ID 贯穿 |
| P0-INF-05 | 迁移框架与基础表 | Alembic 引导；基础表：tenant / user / role / user_role / audit_log（均含 tenant_id 语义预留、时间戳、软删除约定） |
| P0-INF-06 | `scripts/smoke/` 冒烟脚本 | 校验各组件可达、AGE 可执行 openCypher、Milvus 可建集合、MinerU 可解析样例 PDF |

### CORE 核心领域库

| # | 任务 | 要点 |
|---|---|---|
| P0-CORE-01 | 配置体系 | pydantic-settings 分级配置；AI 供方网关配置骨架（base_url/api_key/model 可配，P1 填充实现） |
| P0-CORE-02 | 存储适配器 | RustFS/S3 客户端封装：put/get/presign/multipart，bucket 约定（原始文件/派生物） |
| P0-CORE-03 | 仓储与服务层模式 | SQLAlchemy 2 async 仓储基类、事务边界约定、错误类型体系（领域异常→HTTP 映射） |

### API 服务

| # | 任务 | 要点 |
|---|---|---|
| P0-API-01 | FastAPI 应用骨架 | app 工厂、中间件链（请求 ID/日志/限流占位）、统一错误结构（code/message/details）、游标分页工具、`/healthz` + `/readyz` |
| P0-API-02 | 认证骨架 | dev 模式签发测试 JWT；中间件读取身份注入 request.state；OIDC 对接仅留接口位 |
| P0-API-03 | OpenAPI 契约产出 | 契约导出脚本 + sdk-ts 生成流水线（占位包先落构建链路） |

### WEB / ADM 前端

| # | 任务 | 要点 |
|---|---|---|
| P0-WEB-01 | 用户端壳子 | Vite+React+Tailwind v4+shadcn/ui 初始化、路由骨架、登录页（dev 登录）、TanStack Query 接入、顶栏布局 |
| P0-ADM-01 | 运维端壳子 | 同栈初始化、shadcn Sidebar 侧边栏菜单骨架（菜单项按 04 文档 IA 预置、页面占位）、登录页 |

### QA 质量

| # | 任务 | 要点 |
|---|---|---|
| P0-QA-01 | 测试框架 | pytest + testcontainers（PG/Milvus/RustFS/Redis）；vitest；契约测试模式（schema 快照）确立 |
