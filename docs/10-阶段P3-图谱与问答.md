## 一、范围

**做**：图谱存储（AGE）与管线、实体主表与 merge_log、混合召回 L3/L4、SSE 流式问答、视频场景切分/转写/关键帧、音频转写、懒转码播放、实体合并审核入口（先在用户端 owner 视角暴露，P4 收编到运维端）。
**不做**：OIDC/OAuth/Webhook、运维端全功能（P4）、K8s、连接器/MCP（后续阶段）。

## 二、任务分解

### CORE 核心领域库

| # | 任务 | 要点 |
|---|---|---|
| P3-CORE-01 | 图谱访问层 | AGE 封装（openCypher、按 space 隔离）；实体主表/merge_log 迁移；确定性实体 ID（hash(space, canonical_name, type)） |
| P3-CORE-02 | 合并抽取协议 | 分批调用同时返回 chunk_markers+entities+relations 的 prompt 与校验器；独立校验互不牵连（graph_status=pending_retry 降级） |
| P3-CORE-03 | 实体合并两阶段 | 内联链接（规范名精确+Milvus entities 向量 top-1 阈值）；空间级异步合并（advisory lock、merge_log、可回滚） |
| P3-CORE-04 | 三路混合召回 | 实体链接（查询侧）→ AGE 1~2 跳扩展 → chunk_ids 回收；RRF 融合 L1/L2/L3；邻接补全候选池；L4 社区摘要通道；降级路径（链接失败/空图谱→L1+L2） |
| P3-CORE-05 | 问答服务 | 检索→重排→LLM 生成（引用标注约束）、用户级会话存储（召回范围多空间）、无定位引用不展示编号、证据链（graph_evidence）组装；图谱联合召回常态开启 |

### WRK 管线执行器

| # | 任务 | 要点 |
|---|---|---|
| P3-WRK-01 | 合并抽取入管线 | P1 分片步骤升级为合并调用（prompt 缓存键含 prompt 版本）；图谱写入按资产单事务（PG 主表→AGE→Milvus entities，幂等 upsert） |
| P3-WRK-02 | 社区任务 | Leiden（per space）+ LLM 社区摘要 → community_summary 语义单元入 Milvus；低优先级队列 |
| P3-WRK-03 | 视频管线 | ffprobe 元数据 → PySceneDetect 场景切分 → 代表帧（缩略图+clip_dense）→ VLM 场景 caption → 全部带 {time_start,time_end} |
| P3-WRK-04 | 音频/转写管线 | faster-whisper 转写 → 时间戳分块 → 文本通道；视频音频轨复用 |
| P3-WRK-05 | 懒转码服务 | 首次播放触发预览转码（ffmpeg → H.264/AAC）、产物入 asset_rendition 缓存复用、转码进度事件 |
