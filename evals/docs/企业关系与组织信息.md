# 企业关系与组织信息

## 集团股权结构

华山制造集团有限公司（简称华山制造）是云枢控股集团股份有限公司（简称云枢控股）的全资子公司，持股比例 100%。
云枢控股集团股份有限公司的控股股东为岭南资本管理有限公司，持有 55% 股权。
岭南资本管理有限公司的法定代表人是陈国峰，注册资本 8 亿元人民币，注册地为广州市天河区。
云枢控股集团股份有限公司的法定代表人是林静怡，董事长由林静怡兼任。
华山制造集团有限公司的法定代表人是赵宏图，总经理为孙立敏。

## 主要供应商与客户

华山制造的核心供应商为南粤精密零部件厂，年采购额约 4,500 万元；第二大供应商为东海金属材料有限公司。
云枢控股的财务审计机构为德衡会计师事务所；法律顾问为珠江律师事务所。
南粤精密零部件厂的母公司是北方重工集团股份有限公司。
